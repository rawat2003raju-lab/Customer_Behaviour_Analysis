# 👨🏻‍💻 Customer Behavior Data Analyst Project

This project represents a complete, industry-standard, end-to-end data analytics workflow, designed to mirror the real responsibilities of professional analysts in modern business environments. It covers all critical stages of data analysis — from data preparation and modeling to insight generation, visualization, and reporting.

## 🎯 Who This Project Is For

- 📊 Data Analyst aspirants who want to build a strong **portfolio project** for interviews and LinkedIn
- 📚 Anyone learning Python, SQL, and Power BI
- 💼 Professionals preparing for interviews in Data Analytics, Data Science, or Product Analytics roles

## 📌 Project Overview

The goal of this project is to simulate a corporate-grade, end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence through the following stages:

- ✅ **Data Preparation, Modeling & Exploratory Data Analysis (Python)** — Clean and transform the raw dataset for analysis.
- ✅ **Data Analysis (SQL)** — Simulate business transactions and run queries to extract insights on customer segments, loyalty, and purchase drivers.
- ✅ **Visualization & Insights (Power BI)** — Build an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

## 🗂️ Repository Structure

| File | Description |
|------|--------------|
| `customer_shopping_behavior.csv` | Raw dataset |
| `customer_behaviour_cleaned.csv` | Cleaned dataset after preprocessing |
| `Untitled11.ipynb` | Jupyter Notebook — data cleaning, transformation & EDA |
| `customer_behaviour.sql` | SQL scripts for querying customer behavior insights |
| `Customer Behaviour Dashboard1.pbix` | Power BI dashboard file |
| `LICENSE` | MIT License |
| `README.md` | Project documentation |

## 🛠️ Tools & Technologies

- **Python** (Pandas, NumPy, Matplotlib/Seaborn) — data cleaning & EDA
- **SQL** — querying and business insight extraction
- **Power BI** — interactive dashboard and visualization

## 🚀 How to Use

1. Clone the repository:
```bash
   git clone https://github.com/rawat2003raju-lab/Customer_Behaviour_Analysis.git
```
2. Open `Untitled11.ipynb` in Jupyter Notebook to review the data cleaning and EDA process.
3. Run the queries in `customer_behaviour.sql` against the cleaned dataset to explore business insights.
4. Open `Customer Behaviour Dashboard1.pbix` in Power BI Desktop to explore the interactive dashboard.

## 📈 Key Insights Explored

- Customer segmentation and demographics
- Purchase frequency and loyalty patterns
- Key drivers behind customer purchase decisions
- Trends across product categories and spending behavior
